# 后台管理端

## 启动和访问

后台页面由 FastAPI 同源提供：

```text
http://localhost:8000/admin/
```

数据库升级后，先注册一个普通用户，再在 backend 目录执行：

```powershell
python scripts/create_admin.py user@example.com
```

之后使用这个账号登录后台。普通用户登录移动端仍然可以使用，但访问 `/api/admin/*` 会返回 `403`。

## 当前模块

| 模块 | 能力 | 边界 |
| --- | --- | --- |
| 总览 | 用户、进行中计划、待审核打卡、待处理争议、结算数量 | 统计只读 |
| 用户 | 按邮箱或昵称查询账号和角色 | 当前版本不在后台修改用户资料 |
| 计划 | 按状态查看对赌计划、赌金和期限 | 不直接改计划状态和冻结资金 |
| 打卡审核 | 通过或驳回异常打卡，记录管理员 ID | 审核结果仍影响排行榜和进度统计 |
| 争议处理 | 查看争议、标记处理中/解决/驳回、写处理备注 | 不在页面直接改余额，结算需走资金服务 |
| 资金结算 | 查看结算分配、交易流水、用户可用/冻结余额 | 只读，不能从后台直接改余额 |
| 审计日志 | 查看后台审核和争议处理动作 | 日志只能由服务端写入 |

### 状态边界

- 打卡审核只允许 `pending -> approved/rejected`，已处理记录不能从后台重复改写。
- 争议允许 `pending -> under_review/resolved/rejected`，`under_review -> resolved/rejected`；`resolved` 和 `rejected` 为终态。
- 争议状态更新只处理争议记录和审计日志，资金发放仍由结算/资金服务负责，避免后台按钮绕过资金安全规则。

## 权限原则

管理员权限由 `users.role` 字段控制，迁移 `010_add_user_role` 为历史用户设置 `user` 默认值。后台接口每次从数据库读取当前用户角色，令牌本身不携带可伪造的管理员标记。
